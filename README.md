# CYBER SURVIVOR 3D

ネオンの電脳空間を生き延びる、ブラウザで遊べる3Dサバイバルアクション。
Three.js 製・単一HTMLファイル・インストール不要。

**▶ Play:** https://general9187-byte.github.io/-/

## 操作

| 環境 | 操作 |
|---|---|
| PC | `WASD` / 矢印キーで移動 |
| スマホ | 画面をスワイプ(仮想スティック) |

攻撃は自動です。敵を倒して EXP ジェムを集め、レベルアップで強化を選びます。

## 武器・強化

- 自動射撃(連射・マルチショット・攻撃力強化)
- オービットブレード(周回する刃)
- メガ粒子レーザー(最寄りの敵に向けた貫通砲)
- ブーストエンジン / ナノリペア

## 敵

| 敵 | 特徴 |
|---|---|
| 通常 / 硬い敵 | 基本の追跡型 |
| ダッシャー(黄) | 非常に速い突進型 |
| シューター(紫) | 距離を保って弾を撃つ |
| キャリア(金) | 接触ダメージなし。倒すとアイテムをドロップ |
| ボス | フェーズ突入ごとに出現 |

## アイテム

- 💚 HP回復(最大HPの35%)
- 🧲 マグネット(5秒間、EXPジェムを全吸引)
- 💣 ボム(周囲の敵に大ダメージ、敵弾を消去)

## フェーズ制

60秒ごとにフェーズが進行し、難易度が上がります。
突入時にボス出現・敵の波・HP回復ボーナスが発生し、フェーズ中盤にはダッシャーの群れ(SWARM)が襲来します。
フェーズ6以降は無限モードで、さらに強くなり続けます。
調整は `index.html` 内の `PHASES` テーブルで行えます。

## 障害物

紫の柱がプレイヤーと敵の移動を妨げ、敵弾を遮ります。

## 開発

ビルド不要です。`index.html` をブラウザで開くだけで動きます。
Three.js (r128) は cdnjs から読み込みます(オフラインでは動作しません)。
